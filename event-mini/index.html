Start in three steps

  1. Click Download v0.8 ZIP, then Windows Explorer → Extract All.
  2. Double-click Launch Kathana Widget.bat inside the extracted folder (Microsoft Edge required).
  3. Use MINI for 248px, REGULAR for 312px, or SKINS to customize your colors.

Detailed manuals in the package: README.md (full user guide) and SKINS-ELI5.md (make your own themes with zero programming). The source documents are also available in the GitHub project folder.
