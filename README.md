# Kathana Taney Calculator

Public calculator for Kathana Online Taney pack pricing and in-game Rupiah equivalents.

## Features

- Taney pack comparison for 420, 860, 1,750, 2,640, and 4,000 Taney packs
- Live USD exchange-rate conversion with fallback reference rates
- Manual card/bank FX-rate override
- In-game Rupiah equivalent based on 5M Rupiah = 185 Taney
- Multi-currency comparison including PHP, IDR, BRL, CNY, KRW, and AED
- Responsive single-page interface

## Public site

https://apxinfinity.github.io/kathana-taney-calculator/

## Notes

Currency conversions are estimates. Actual checkout totals can differ due to taxes, fees, regional pricing, and card-provider exchange rates.
